对，这两个方案**不矛盾**，最佳实践应该是把它们合并成两层：

```text
第一层：detect_page_block()
    做更丰富的检测，返回 kind / confidence / signals / score
    用于日志、调试、后续策略扩展

第二层：should_degrade_page()
    根据检测结果返回 bool
    专门服务自动降级链
```

这样既保留了第一版的**可诊断性**，也保留了第二版的**降级链稳定性**。

---

# 推荐最终设计

不要继续用：

```python
looks_like_anti_crawl(text) -> bool
```

作为唯一入口。

改成：

```python
detect_page_block(...) -> PageBlockDetection
should_degrade_page(...) -> bool
looks_like_anti_crawl(...) -> bool  # 兼容旧调用
```

语义：

```text
detect_page_block:
    判断页面像什么问题，并记录信号

should_degrade_page:
    只判断是否应该触发降级

looks_like_anti_crawl:
    旧函数兼容包装，内部调用 should_degrade_page
```

这样后续 `FetchCoordinator` 仍然只需要 bool，但日志可以更清楚。

# 推荐代码

```python
import re
from dataclasses import dataclass, field
from typing import Optional


ANTI_CRAWL_SCAN_CHARS = 30000

PAGE_BLOCK_KINDS = {
    "normal",
    "bot_challenge",
    "captcha",
    "auth_required",
    "access_denied",
    "rate_limited",
    "js_required",
    "spa_shell",
}


HIGH_CONFIDENCE_PATTERNS = (
    "cf-chl",
    "cf-turnstile",
    "challenge-platform",
    "challenges.cloudflare.com",
    "g-recaptcha",
    "grecaptcha",
    "www.google.com/recaptcha",
    "h-captcha",
    "hcaptcha",
    "api.hcaptcha.com",
)

BOT_CHALLENGE_PATTERNS = (
    "just a moment",
    "checking your browser",
    "verify you are human",
    "verifying you are human",
    "are you a robot",
    "are you human",
    "请完成验证",
    "安全验证",
)

CAPTCHA_PATTERNS = (
    "captcha",
    "验证码",
    "人机验证",
)

JS_REQUIRED_PATTERNS = (
    "please enable javascript",
    "please enable js",
    "enable javascript to continue",
    "javascript is required",
    "requires javascript",
    "请开启 javascript",
    "请启用 javascript",
)

ACCESS_DENIED_PATTERNS = (
    "access denied",
    "request blocked",
    "temporarily blocked",
    "forbidden",
    "访问受限",
    "请求被拦截",
    "没有权限",
)

RATE_LIMIT_PATTERNS = (
    "too many requests",
    "rate limit",
    "temporarily blocked",
    "unusual traffic",
    "访问过于频繁",
    "请求过于频繁",
)

AUTH_REQUIRED_PATTERNS = (
    "please sign in",
    "please log in",
    "login required",
    "sign in to continue",
    "log in to continue",
    "unauthorized",
    "需要登录",
    "请登录",
    "登录后查看",
    "请先登录",
)

SPA_SHELL_PATTERNS = (
    'id="root"',
    "id='root'",
    'id="app"',
    "id='app'",
    "__next",
    "webpack",
    "vite",
)


@dataclass
class PageBlockDetection:
    kind: str = "normal"
    confidence: float = 0.0
    score: int = 0
    signals: list[str] = field(default_factory=list)

    @property
    def blocked(self) -> bool:
        return self.kind != "normal"


def detect_page_block(
    text: str,
    *,
    html: str = "",
    title: str = "",
    url: str = "",
    status_code: Optional[int] = None,
) -> PageBlockDetection:
    """检测页面是否疑似登录、验证码、反爬、JS 空壳或权限页。

    该函数负责“识别和记录信号”，不直接代表降级策略。
    降级策略由 should_degrade_page 控制。
    """
    if not text and not html and not title and not url and status_code is None:
        return PageBlockDetection()

    sample = "\n".join(
        part[:ANTI_CRAWL_SCAN_CHARS]
        for part in (title, url, html, text)
        if part
    )
    lower = sample.lower()

    visible_text = text[:ANTI_CRAWL_SCAN_CHARS]
    visible_length = len(re.sub(r"\s+", "", visible_text))

    signals: list[str] = []

    if status_code == 401:
        return PageBlockDetection(
            kind="auth_required",
            confidence=0.95,
            score=5,
            signals=["http_status:401"],
        )

    if status_code == 403:
        return PageBlockDetection(
            kind="access_denied",
            confidence=0.95,
            score=5,
            signals=["http_status:403"],
        )

    if status_code == 429:
        return PageBlockDetection(
            kind="rate_limited",
            confidence=0.95,
            score=5,
            signals=["http_status:429"],
        )

    high_confidence_hits = _match_patterns(lower, HIGH_CONFIDENCE_PATTERNS)
    if high_confidence_hits:
        return PageBlockDetection(
            kind="captcha" if _has_any(high_confidence_hits, ("captcha", "recaptcha", "hcaptcha")) else "bot_challenge",
            confidence=0.95,
            score=5,
            signals=[f"high_confidence:{hit}" for hit in high_confidence_hits[:5]],
        )

    groups = [
        ("bot_challenge", BOT_CHALLENGE_PATTERNS, 2),
        ("captcha", CAPTCHA_PATTERNS, 2),
        ("js_required", JS_REQUIRED_PATTERNS, 2),
        ("access_denied", ACCESS_DENIED_PATTERNS, 2),
        ("rate_limited", RATE_LIMIT_PATTERNS, 2),
        ("auth_required", AUTH_REQUIRED_PATTERNS, 1),
    ]

    best_kind = "normal"
    best_score = 0

    for kind, patterns, single_hit_score in groups:
        hits = _match_patterns(lower, patterns)

        if len(hits) >= 2:
            return PageBlockDetection(
                kind=kind,
                confidence=0.9,
                score=4,
                signals=[f"{kind}:{hit}" for hit in hits[:5]],
            )

        if len(hits) == 1:
            score = single_hit_score
            signals.append(f"{kind}:{hits[0]}")

            if visible_length < 500:
                score += 1
                signals.append("short_visible_text")

            if score > best_score:
                best_score = score
                best_kind = kind

    spa_hits = _match_patterns(lower, SPA_SHELL_PATTERNS)
    if visible_length < 300 and spa_hits:
        score = best_score + 2
        return PageBlockDetection(
            kind="spa_shell",
            confidence=0.75 if score >= 3 else 0.6,
            score=score,
            signals=signals + [f"spa_shell:{hit}" for hit in spa_hits[:5]],
        )

    if best_score >= 3:
        return PageBlockDetection(
            kind=best_kind,
            confidence=0.75,
            score=best_score,
            signals=signals[:8],
        )

    return PageBlockDetection(
        kind="normal",
        confidence=0.0,
        score=best_score,
        signals=signals[:8],
    )


def should_degrade_page(
    text: str,
    *,
    html: str = "",
    title: str = "",
    url: str = "",
    status_code: Optional[int] = None,
) -> bool:
    """判断是否应该触发抓取降级。

    设计原则：
    - 降级判断偏高置信，避免正常正文被误杀。
    - 对明确验证码、权限、JS 空壳、HTTP 阻断直接降级。
    - 单个弱关键词不直接降级。
    """
    detection = detect_page_block(
        text,
        html=html,
        title=title,
        url=url,
        status_code=status_code,
    )

    if detection.kind in {
        "bot_challenge",
        "captcha",
        "auth_required",
        "access_denied",
        "rate_limited",
        "js_required",
        "spa_shell",
    }:
        return detection.confidence >= 0.7 or detection.score >= 3

    return False


def looks_like_anti_crawl(text: str, *, html: str = "") -> bool:
    """兼容旧调用：用于判断是否触发抓取降级。"""
    return should_degrade_page(text, html=html)


def _match_patterns(text: str, patterns: tuple[str, ...]) -> list[str]:
    return [pattern for pattern in patterns if pattern in text]


def _has_any(values: list[str], needles: tuple[str, ...]) -> bool:
    return any(needle in value for value in values for needle in needles)
```

---

# 为什么这个更好

## 1. 不破坏降级链

上层仍然可以继续写：

```python
if looks_like_anti_crawl(result, html=html):
    return None
```

所以现有链路不需要大改。

---

## 2. 内部保留检测细节

将来你想增强日志时，可以这样：

```python
detection = detect_page_block(result, html=html)

if should_degrade_page(result, html=html):
    log_fail(
        "HTML 清洗",
        "疑似反爬/登录/JS 空壳页面，触发降级",
        kind=detection.kind,
        confidence=detection.confidence,
        score=detection.score,
        signals=",".join(detection.signals[:5]),
    )
    return None
```

这样比单纯：

```text
疑似反爬/错误页面
```

更容易排查。

---

## 3. 减少误杀

普通正文里出现：

```text
This article explains Cloudflare captcha.
```

不会直接降级。

因为：

```text
单个 captcha / cloudflare 弱命中
visible_length 不一定短
score 不够
```

---

## 4. 对强信号更敏感

HTML 里出现：

```html
<div class="g-recaptcha"></div>
```

或者：

```html
<div class="cf-turnstile"></div>
```

直接降级。

这比扫清洗后的正文更稳，因为这些强信号通常在 HTML 结构里，不一定会进入正文。

# 最终结论

更好的实践是：

```text
检测层保留细节；
策略层返回 bool；
兼容层保留旧函数。
```

也就是：

```text
detect_page_block      用于识别和日志
should_degrade_page    用于降级链
looks_like_anti_crawl  兼容旧调用
```

这比单纯分类更轻，也比单纯 bool 更稳。
