确实更差了，而且这次不是 `get_content / navigation / control` 那几个文件导致的。**根因已经非常集中：模型没有理解 ref 协议。**

日志里链路很清楚：

1. 它先 `navigate` 成功打开 Wikipedia。
2. 它没有先 snapshot，直接调用：

```json
{"type": "fill_ref", "ref": "search", "text": "apple"}
```

于是返回 `SNAPSHOT_REQUIRED`。

3. 它随后 `snapshot` 成功，而且 snapshot 已经明确给出了：

```text
[e5] searchbox 'Search Wikipedia' [fillable]
[e6] button 'Search'
```

这说明工具已经把正确 ref 暴露出来了。

4. 但模型下一步没有用 `e5`，而是连续使用：

```json
{"ref": "searchbox"}
{"ref": "search"}
```

然后反复收到 `invalid ref: searchbox` / `invalid ref: search`。

所以这不是页面问题，不是 snapshot 抓不到，也不是 fill_ref 本身坏了。**它是工具说明 / schema / 输出格式没有把“ref 必须是 e5 这种编号”压到模型行为里。**

---

## 为什么会这样

当前 snapshot tree 这种格式：

```text
[e5] searchbox 'Search Wikipedia' [fillable]
```

对人很清楚，但对模型来说，它把三种东西混在一行：

```text
ref: e5
role: searchbox
label: Search Wikipedia
```

模型现在明显把 `role` 当成了 `ref`。它不是不知道要填搜索框，它知道；但它把 `"searchbox"` 填进了 `ref` 字段。

所以现在继续改 action handler 没意义。要改的是 **工具接口契约呈现方式**。

---

# 必须改的方向

## 1. snapshot tree 改成显式字段格式

不要再用：

```text
[e5] searchbox 'Search Wikipedia' [fillable]
```

改成：

```text
ref=e5 role=searchbox label="Search Wikipedia" flags=[fillable]
```

更强一点：

```text
REF e5 | role=searchbox | label="Search Wikipedia" | flags=fillable
```

目标是让模型看到：

```text
ref=e5
```

而不是把 `[e5] searchbox` 当成自然语言描述。

---

## 2. tool schema 里给 `ref` 加 pattern 和硬描述

`ref` 字段必须写得非常硬：

```json
{
  "type": "string",
  "pattern": "^e[1-9][0-9]*$",
  "description": "Exact ref id from snapshot, such as e5. Do not use role names like searchbox, button, link, textbox, or labels like Search."
}
```

现在模型能传 `"search"` / `"searchbox"`，说明 schema 对 `ref` 的约束和描述不够强，或者 action schema 没给每个 action 分支限制清楚。

---

## 3. invalid ref 的错误信息要直接纠偏

现在错误是：

```json
"message": "invalid ref: searchbox"
```

这个信息太弱。模型不知道怎么修。

改成：

```text
Invalid ref 'searchbox'. Ref must be an exact id from the latest snapshot, such as e5. Do not use role names like searchbox/button/link or labels like Search.
```

这不是恢复建议过度规划，而是参数格式纠错。

`make_schema_error` 的 message 可以更具体，尤其是 `selector_or_error_response()` 里。

---

## 4. 测试 prompt 也要强制 ref 规则

现在你的 prompt 可能只是说“搜索 apple”。模型会自己猜字段。

action 覆盖测试里应该写：

```text
先 snapshot。然后只能使用 snapshot.tree 中的 ref=e数字，例如 e5。不要使用 role 名称 searchbox/button/link 作为 ref。
```

这不是投机，这是测试目标。如果测试是为了验证工具能不能正确使用 ref，就必须把规则写清楚。
