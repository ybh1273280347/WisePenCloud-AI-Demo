这份 `tool_content_store.py` 兼容层整体思路对，但我会给它一个结论：

> **函数级兼容基本 OK，对象级兼容不够。**
> 最大风险是 `tool_content_store = content_store` 这行。

---

# 1. 最大问题：`tool_content_store = content_store` 不是真兼容

旧代码里 `tool_content_store` 是 `ToolContentStore` 实例，可能支持：

```python
tool_content_store.put(
    session_id=...,
    tool_name=...,
    source=...,
    text=...,
)
```

但现在：

```python
tool_content_store = content_store
```

而 `content_store` 是 `ContentStore` 实例，它大概率只有：

```python
put_content(...)
get_content(...)
read_window(..., scope_id=...)
```

这意味着旧调用：

```python
tool_content_store.put(...)
tool_content_store.get(...)
tool_content_store.read_window(session_id=...)
```

可能会直接坏。

报告里说旧测试已经改成新 API，这会掩盖这个问题。**如果目标是兼容层，就不应该只兼容函数，还要兼容旧对象方法。**

建议改成这样：

```python
class ToolContentStore:
    def __init__(
        self,
        ttl_seconds: Optional[int] = None,
        max_total_chars: Optional[int] = None,
        default_chunk_size: Optional[int] = None,
        max_item_chars: Optional[int] = None,
    ):
        self._store = ContentStore(
            repository=TTLContentRepository(
                ttl_seconds=ttl_seconds or settings.TOOL_CONTENT_STORE_TTL_SECONDS,
                max_total_chars=max_total_chars or settings.TOOL_CONTENT_STORE_MAX_TOTAL_CHARS,
            ),
            default_chunk_size=default_chunk_size or settings.TOOL_RESULT_MAX_CHARS,
            max_item_chars=max_item_chars or settings.TOOL_CONTENT_STORE_MAX_ITEM_CHARS,
            normalize_text=True,
        )

    def put(
        self,
        *,
        session_id: str,
        tool_name: str,
        source: str,
        text: str,
        content_type: str = "text/markdown",
        metadata: Optional[Dict[str, Any]] = None,
    ) -> Optional[str]:
        return self._store.put_content(
            scope_id=session_id,
            producer=tool_name,
            source=source,
            text=text,
            content_type=content_type,
            metadata=metadata,
        )

    def get(self, *, content_id: str, session_id: str):
        return self._store.get_content(
            content_id=content_id,
            scope_id=session_id,
        )

    def read_window(
        self,
        *,
        content_id: str,
        session_id: str,
        offset: int,
        limit: int,
    ) -> Optional[ContentWindow]:
        return self._store.read_window(
            content_id=content_id,
            scope_id=session_id,
            offset=offset,
            limit=limit,
        )

    def put_and_read_window(
        self,
        *,
        session_id: str,
        tool_name: str,
        source: str,
        text: str,
        content_type: str = "text/markdown",
        metadata: Optional[Dict[str, Any]] = None,
        offset: int = 0,
        limit: Optional[int] = None,
    ) -> ContentWindow:
        return self._store.put_and_read_window(
            scope_id=session_id,
            producer=tool_name,
            source=source,
            text=text,
            content_type=content_type,
            metadata=metadata,
            offset=offset,
            limit=limit,
        )


tool_content_store = ToolContentStore()
```

然后 `cache_and_window` 用：

```python
window = tool_content_store.put_and_read_window(...)
```

而不是直接绑死到 `content_store`。

# 2. 旧类型别名可能是“假兼容”

你现在有：

```python
from chat.core.content_store.models import (
    ContentChunk,
    StoredContent,
    StoredToolContent,
    WindowedContent,
)
```

这取决于 `models.py` 里怎么写。

如果只是：

```python
StoredToolContent = StoredContent
WindowedContent = ContentWindow
```

那不一定兼容。

因为旧字段是：

```python
StoredToolContent.session_id
StoredToolContent.tool_name
WindowedContent.tool_name
WindowedContent.content_cached
```

新字段是：

```python
StoredContent.scope_id
StoredContent.producer
ContentWindow.producer
ContentWindow.cached
```

如果外部代码直接访问：

```python
window.content_cached
window.tool_name
item.session_id
item.tool_name
```

就会坏。

建议在新 dataclass 里加兼容 property：

```python
@dataclass(slots=True)
class StoredContent:
    ...

    @property
    def session_id(self) -> str:
        return self.scope_id

    @property
    def tool_name(self) -> str:
        return self.producer
```

```python
@dataclass(slots=True)
class ContentWindow:
    ...

    @property
    def tool_name(self) -> str:
        return self.producer

    @property
    def content_cached(self) -> bool:
        return self.cached
```

这样 `WindowedContent = ContentWindow` 才比较安全。

# 5. `read_tool_content_window` 基本 OK

这段没大问题：

```python
content_id = content_id.strip()

if not content_id:
    return "[Tool Error] Missing required content_id parameter"
```

不过更稳一点可以处理非字符串输入：

```python
if not isinstance(content_id, str):
    return "[Tool Error] Missing required content_id parameter"

content_id = content_id.strip()
```

工具 schema 理论上会保证 string，但运行时工具参数不一定永远干净。

# 6. `cache_and_window` 的 `limit` 是否需要封顶

当前：

```python
limit: int = 4000
```

然后直接传给：

```python
content_store.put_and_read_window(..., limit=limit)
```

如果 `ContentStore.read_window` 内部已经处理：

```python
limit = max(1, limit)
```

那没问题。

但如果你希望工具返回不超过：

```python
settings.TOOL_RESULT_MAX_CHARS
```

那么 `cache_and_window` 这里也应该像 `read_tool_content_window` 一样封顶：

```python
limit = min(max(1, limit), settings.TOOL_RESULT_MAX_CHARS)
```

不过这里要看旧行为。旧 `cache_and_window` 是否允许更大的 limit？
如果旧行为没有封顶，为了避免行为变化，可以暂时不动。

# 7. 我建议这份文件改成这样

核心结构：

```python
from typing import Any, Dict, Optional

from chat.core.config.app_settings import settings
from chat.core.content_store import (
    ContentStore,
    ContentWindow,
    TTLContentRepository,
    create_uncached_window,
    format_tool_content_window,
)
from chat.core.content_store.models import (
    ContentChunk,
    StoredContent,
    StoredToolContent,
    WindowedContent,
)


class ToolContentStore:
    def __init__(
        self,
        ttl_seconds: Optional[int] = None,
        max_total_chars: Optional[int] = None,
        default_chunk_size: Optional[int] = None,
        max_item_chars: Optional[int] = None,
    ):
        self._store = ContentStore(
            repository=TTLContentRepository(
                ttl_seconds=ttl_seconds or settings.TOOL_CONTENT_STORE_TTL_SECONDS,
                max_total_chars=max_total_chars or settings.TOOL_CONTENT_STORE_MAX_TOTAL_CHARS,
            ),
            default_chunk_size=default_chunk_size or settings.TOOL_RESULT_MAX_CHARS,
            max_item_chars=max_item_chars or settings.TOOL_CONTENT_STORE_MAX_ITEM_CHARS,
            normalize_text=True,
        )

    def put(
        self,
        *,
        session_id: str,
        tool_name: str,
        source: str,
        text: str,
        content_type: str = "text/markdown",
        metadata: Optional[Dict[str, Any]] = None,
    ) -> Optional[str]:
        return self._store.put_content(
            scope_id=session_id,
            producer=tool_name,
            source=source,
            text=text,
            content_type=content_type,
            metadata=metadata,
        )

    def get(self, *, content_id: str, session_id: str) -> Optional[StoredContent]:
        return self._store.get_content(
            content_id=content_id,
            scope_id=session_id,
        )

    def read_window(
        self,
        *,
        content_id: str,
        session_id: str,
        offset: int,
        limit: int,
    ) -> Optional[ContentWindow]:
        return self._store.read_window(
            content_id=content_id,
            scope_id=session_id,
            offset=offset,
            limit=limit,
        )

    def put_and_read_window(
        self,
        *,
        session_id: str,
        tool_name: str,
        source: str,
        text: str,
        content_type: str = "text/markdown",
        metadata: Optional[Dict[str, Any]] = None,
        offset: int = 0,
        limit: Optional[int] = None,
    ) -> ContentWindow:
        return self._store.put_and_read_window(
            scope_id=session_id,
            producer=tool_name,
            source=source,
            text=text,
            content_type=content_type,
            metadata=metadata,
            offset=offset,
            limit=limit,
        )


tool_content_store = ToolContentStore()


def cache_and_window(
    *,
    session_id: str,
    tool_name: str,
    source: str,
    text: str,
    content_type: str = "text/markdown",
    metadata: Optional[Dict[str, Any]] = None,
    offset: int = 0,
    limit: int = 4000,
) -> ContentWindow:
    return tool_content_store.put_and_read_window(
        session_id=session_id,
        tool_name=tool_name,
        source=source,
        text=text,
        content_type=content_type,
        metadata=metadata,
        offset=offset,
        limit=limit,
    )


def cache_and_format(
    *,
    session_id: str,
    tool_name: str,
    source: str,
    text: str,
    content_type: str = "text/markdown",
    metadata: Optional[Dict[str, Any]] = None,
    offset: int = 0,
    limit: int = 4000,
) -> str:
    window = cache_and_window(
        session_id=session_id,
        tool_name=tool_name,
        source=source,
        text=text,
        content_type=content_type,
        metadata=metadata,
        offset=offset,
        limit=limit,
    )
    return format_tool_content_window(window)


def read_tool_content_window(
    *,
    session_id: str,
    content_id: str,
    offset: int = 0,
    limit: Optional[int] = None,
) -> str:
    if not isinstance(content_id, str):
        return "[Tool Error] Missing required content_id parameter"

    content_id = content_id.strip()

    if not content_id:
        return "[Tool Error] Missing required content_id parameter"

    if limit is None:
        limit = settings.TOOL_RESULT_MAX_CHARS

    offset = max(0, offset)
    limit = min(max(1, limit), settings.TOOL_RESULT_MAX_CHARS)

    window = tool_content_store.read_window(
        content_id=content_id,
        session_id=session_id,
        offset=offset,
        limit=limit,
    )

    if window is None:
        return "[Tool Result] Cached tool content not found, expired, or inaccessible."

    return format_tool_content_window(window)


format_windowed_content = format_tool_content_window


__all__ = [
    "ContentChunk",
    "StoredContent",
    "StoredToolContent",
    "ContentWindow",
    "WindowedContent",
    "ToolContentStore",
    "tool_content_store",
    "cache_and_window",
    "cache_and_format",
    "read_tool_content_window",
    "format_windowed_content",
    "create_uncached_window",
]
```

# 结论

这份 `tool_content_store.py` 现在**函数层面基本可用**，但作为“兼容层”还不够完整。

最需要改的是：

```python
tool_content_store = content_store
```

建议替换为真正的 `ToolContentStore` wrapper。

同时在 `ContentWindow` / `StoredContent` 上补：

```python
tool_name
content_cached
session_id
```

这些 compatibility property。

否则旧测试如果都改成新 API，迁移看起来会绿，但旧调用方仍可能在运行时炸。
